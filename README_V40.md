# V40 渠道结算最终规则

本版以 V39 为基础，按最新确认的 4 条需求收敛渠道结算：

1. 渠道结算不展示上级代理，渠道相关表格单元格间距在 V39 基础上继续压缩约 30%，整体更紧凑。
2. 渠道结算默认日期为空：不选择日期时显示每个可见代理的历史真实支付总流水；选择一个日期后只显示该北京时间自然日的流水。日期选择恢复为单个紧凑日期框，不再提供日期区间选择。
3. 渠道结算表仅保留 7 列，并固定顺序：代理ID、代理账号、代理等级、代理名称、总流水/当日流水、佣金比例、日期。默认列名为“总流水”，选择日期后动态显示“当日流水”；日期为空时显示“全部时间”。
4. 等级查询按角色限制：超级管理员可选一级/二级/三级；一级代理只可选二级；二级代理只可选三级。三级代理没有下级，因此没有 `settlements.view` 权限，左侧不显示渠道结算，直接访问接口也会被拒绝。
5. 流水继续只统计 `pay_status=paid` 且 `paid_at` 非空的真实平台币支付订单；商城订单、未支付订单、手工发放/收回平台币均不进入流水或分佣。
6. 结果继续按流水金额从高到低排序。超管查看全部代理；一级/二级代理默认查看自己代理树中的下级代理，不包含自己。

兼容说明：V39 的 `start_date/end_date` 参数仅在两者为同一天时兼容；真正的日期区间会返回 400，提示渠道结算仅支持单日查询。数据库无需重建。
