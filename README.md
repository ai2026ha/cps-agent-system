# V23 数据总览流水口径 + 紧凑布局补丁

适用于 V22 及之后版本。

本补丁包含：

- 数据总览的总流水、昨日流水、今日流水，仅统计 `pay_status = paid` 的平台币订单。
- 商城订单不计入数据总览流水。
- 未支付的平台币订单不计入数据总览流水。
- 今日/昨日优先按支付时间统计，并兼容历史 `paid_at` 为空的已支付订单。
- 代理端昨日分佣、今日分佣、总计分佣基于同一平台币已支付流水口径计算。
- 保留 V22 的紧凑数据总览布局、较小卡片、缩短留白和整体上移效果。
- 静态资源版本号升级为 V23，降低 Render 部署后浏览器旧缓存影响。

覆盖 GitHub 中同路径文件后提交，等待 Render 自动部署完成，再使用 Ctrl+F5 强制刷新。
