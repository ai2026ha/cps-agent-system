# V53 商城购买计入累计充值奖励进度

本版在 V52 玩家中心商城基础上调整累计充值口径：

- 玩家使用平台币购买网页商城礼包后，商城订单仍自动生成。
- 商城购买会增加玩家的“累计充值”奖励进度，计入值为该商城订单实际消耗的平台币数值。
- 商城购买不会增加“今日充值”（今日充值仍只代表真实支付平台币充值）。
- 商城购买绝不会增加渠道流水，也不会产生代理佣金。
- 手工发放/收回平台币仍不会直接增加累计充值、流水或佣金；只有玩家实际完成商城购买时才增加累计充值奖励进度。
- 启动时会重新校准历史玩家累计充值：真实支付平台币充值 + 历史已支付商城礼包消费。
- 玩家列表“总充值”文案调整为“累计充值”，以对应累充奖励用途。

注意：当前商城订单金额保存的是平台币消费数值，因此商城部分计入的是平台币数值；真实支付充值部分仍沿用真实支付订单金额。流水与佣金始终只使用真实支付订单金额，不受该累计奖励进度影响。
