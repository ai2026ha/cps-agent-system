# V52：玩家中心 + 平台币网页礼包商城

- 玩家通过代理专属注册地址注册成功后，约 0.9 秒自动跳转到 `/player` 玩家中心登录页，并自动带入刚注册的玩家账号。
- 玩家中心使用独立玩家 JWT；玩家 token 不能访问代理/超管后台 API。
- 玩家登录后显示平台币余额、玩家ID、归属渠道和当前角色，并可进入“礼包商城 / 我的订单”。
- 玩家中心商城只展示后台「产品管理 → 礼包列表」中已启用的礼包。
- 礼包的 `price` 现在作为网页商城的平台币售价；新建礼包时必须填写大于 0 的整数平台币价格。
- 玩家购买时校验账号状态、库存与平台币余额，在同一数据库事务中扣减平台币、扣减库存、写入 `player_coin_ledger` 并自动创建商城订单。
- 商城订单编号自动生成 `MO...`，后台「订单管理 → 商城订单」取消“新增”按钮，POST 手工造单接口返回 405。
- 商城订单不属于人民币充值流水，不增加玩家累计充值，也不产生代理分佣。
- 商城订单后台列表改为显示玩家账号、礼包名称、数量、消耗平台币、支付状态、发货状态和创建时间。
- 发货继续由后台「发货查询」处理；玩家中心“我的订单”可看到待发货/已发货/失败状态。

## 玩家正常流程

`代理注册地址 → 注册成功 → 自动跳转玩家中心登录 → 登录 → 使用平台币购买礼包 → 自动生成商城订单 → 后台发货`

部署不需要删除 PostgreSQL，也没有新增数据库列。旧商城订单继续保留。
