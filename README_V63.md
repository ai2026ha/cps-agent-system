# V63 玩家礼包单次购买与简化展示

- 玩家中心礼包下拉框只显示礼包名称，不再显示平台币价格。
- 选中礼包后，详情区域只显示礼包道具内容及数量，不显示 SKU、库存、售价等附加信息。
- 礼包售价只显示在购买按钮：`价格 平台币 · 立即购买`。
- 移除购买数量输入框，每次固定只能购买 1 个礼包。
- 后端 `PlayerMallPurchase.quantity` 同步限制为 1，禁止绕过前端批量购买。
- 管理后台新增礼包时，礼包内容提示按“一行一个道具，例如：元宝 × 1000”填写，玩家端会将可识别的 `道具 × 数量` 格式拆成两列展示。
- 不改变商城消费累计充值、真实流水、代理佣金等既有统计口径。
