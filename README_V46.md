# V46 平台币订单自动充值记录

## 后台变化

- 「平台币订单」取消后台手工新增入口；`POST /api/orders/platform` 会明确拒绝手工创建。
- 平台币订单由玩家充值/支付服务自动创建，并在支付成功回调后自动更新订单、计入真实支付流水并发放平台币。
- 查询栏新增：订单号、玩家账号、支付方式（微信/支付宝）、状态（未支付/已支付/已发货）。
- 列表固定显示：订单号、玩家账号、商品名称、金额（元）、支付方式、状态、发货、创建时间、支付时间、操作。
- 超级管理员在「操作」最右侧拥有“补发”按钮；只有“已支付 + 发货失败”的订单允许补发。成功订单禁止重复补发，避免重复到账。
- 普通代理仍只查看自己渠道权限范围内的订单，不能补发。

## 自动订单接口

生产环境需要配置 `PAYMENT_CALLBACK_SECRET`。支付/充值服务调用时使用请求头：

`X-Payment-Secret: <PAYMENT_CALLBACK_SECRET>`

1. 创建待支付订单：`POST /api/payment/platform-orders`
2. 支付成功回调：`POST /api/payment/platform-orders/paid`

创建订单时传玩家账号、商品名称、金额、平台币数量、支付方式。代理归属由玩家当前归属自动写入，外部接口不能手工指定代理，避免伪造渠道流水。

支付成功回调具有幂等保护：同一订单重复回调不会重复增加流水、累计充值、平台币余额或代理分佣。

> 本版本完成 CPS 后台订单链路和安全回调接口。真正直连微信支付/支付宝仍需要对应商户号、应用 ID、证书/密钥等商户参数，并按支付平台官方签名规则接入；在这些参数未配置前，不应伪造“真实支付成功”。
