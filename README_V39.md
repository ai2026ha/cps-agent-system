# V39 渠道结算升级说明

本版在 V38 基础上调整渠道管理与渠道结算：

1. 渠道管理代理列表和渠道结算列表不再展示“上级代理”列。
2. 渠道相关表格的单元格间距缩小约 30%，界面更紧凑。
3. 渠道结算默认日期为空，直接进入页面时显示每个可见代理的历史真实支付总流水。
4. 日期查询支持单日和日期区间：只填一个日期自动按该日查询；同时填写开始/结束日期则统计包含首尾日的区间。
5. 结果继续按流水从高到低排序；超管查看全部代理，普通代理只查看自己下级代理树。
6. 流水仍只统计真实支付成功的平台币订单，手工发放/收回平台币不会进入流水或佣金。

数据库无需重建。V38 的 `date=YYYY-MM-DD` 单日 API 参数仍保留兼容。
