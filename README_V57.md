# V57 商城订单角色快照与查询

- 商城订单顶部新增“账号查询”“商品查询”，商品查询同时匹配礼包名称与 SKU。
- 商城订单列表新增“角色名”“区服”。
- 玩家中心购买礼包时新增“购买角色”选择。一个账号有多个区服角色时，必须明确选择角色后购买。
- 新商城订单保存购买瞬间的 character_id、角色名、区服快照；玩家之后切换主角色、改名或转服不会改写历史订单。
- 历史订单因为旧版本没有记录购买角色，不伪造数据，显示“历史订单未记录”。
- 已上线 PostgreSQL 无需重建，启动时自动给 mall_orders 补充 character_id、role_name、server_name 字段。
- 商城订单仍只能由玩家中心实际平台币购买行为自动生成，后台禁止手工造单。
- 原有规则保持：商城消费增加累计充值进度，但不增加真实流水、不产生代理佣金；手工平台币补偿也不进入流水/分佣/累计充值。
