# V42 渠道结算日期区间与横向间距修复

V42 基于 V41 累积升级，修正渠道结算页面两个问题：

- 日期查询恢复为“开始日期 至 结束日期”双日期选择器，默认两端都为空。
- 两端都为空：显示历史总流水；开始/结束为同一天：显示当日流水；选择不同开始/结束日期：显示包含首尾日期的区间流水。
- 只填写开始或结束其中一端时按该单日查询；开始日期晚于结束日期时后端返回明确错误。
- 日期统计继续按北京时间自然日边界转换为 UTC 查询，流水只统计真实支付成功且存在 `paid_at` 的平台币订单。
- 渠道结算表格只缩短左右间距：上下行高保持原来的 `11px`，左右 padding 从 `10px` 缩短到 `7px`（约 30%）。
- 查询区域也只收紧横向 gap/padding，控件高度保持 38px；两个日期输入框采用紧凑宽度。
- 保留 V41 等级查询权限：超管可筛一/二/三级；一级代理可筛二/三级；二级代理可筛三级；三级代理无渠道结算权限。
- 渠道结算结果仍只显示 7 列：代理ID、代理账号、代理等级、代理名称、流水、佣金比例、日期。
