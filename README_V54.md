# V54 — 累计充值口径修正

最终统计口径：

- 真实支付的平台币充值：只进入真实支付流水与代理分佣；不增加累计充值奖励进度。
- `today_recharge`：保留为玩家“今日真实充值”展示字段。
- `total_recharge`（后台显示“累计充值”）：只统计玩家在网页商城实际消耗平台币购买礼包的金额，用于累计充值奖励门槛。
- 商城消费：增加累计充值，但不增加渠道流水、不产生代理佣金。
- 手工发放/收回平台币：既不增加流水/佣金，也不增加累计充值；之后若玩家把这些平台币用于商城购买，则对应商城消费会计入累计充值。
- 启动时会重新校准历史 `total_recharge`：只按已支付商城订单累计，自动移除历史真实充值曾错误计入的部分。

不需要删除 PostgreSQL 数据库。
